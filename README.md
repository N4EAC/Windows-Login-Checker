# Windows-Login-Checker
A simple Windows 10/11 login verification tool which displays all invalid login attempts: Windows Security Event 4625 record

This is a standalone app (no installer).

What it does:<p></p>
Reads real Windows Security Event 4625 records.



Classifies login types and common failure reasons.



Displays usernames, timestamps, source IPs, and workstation names.



Filters records and exports them to CSV.



Runs entirely locally.
